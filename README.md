# ระบบบันทึกเวลาทำงานด้วยการสแกนใบหน้า

หัวหน้างานเปิดหน้าเว็บ → กล้องจับใบหน้าพนักงาน → ระบบบอกได้เองว่าเป็นใคร → บันทึกเวลาเข้า/ออกงานลง Google Sheet
พร้อมคำนวณเวลาสายและชั่วโมงทำงาน และเก็บรูปตอนสแกนลง Google Drive เป็นหลักฐาน

การจดจำใบหน้าทำงานในเบราว์เซอร์ทั้งหมด (face-api.js) — ไม่มีการส่งใบหน้าออกไปยังบริการภายนอก และไม่มีค่าใช้จ่ายรายเดือน

```
เบราว์เซอร์ (index.html + app.js + face.js + models/)
        │  fetch
        ▼
Apps Script Web App (Code.gs ที่ /exec)
        │
        ├──► Google Sheet  (Employees, FaceData, Attendance, ScanLogs, Settings)
        └──► Google Drive  (รูปถ่ายตอนสแกน)
```

---

## ทำไมหน้าเว็บถึงไม่ได้อยู่ใน Apps Script

Apps Script (HtmlService) แสดงหน้าเว็บใน sandbox iframe ที่ **ไม่ได้เปิดสิทธิ์ `camera`** เรียก `getUserMedia()`
จึงล้มด้วยข้อความ *"Permissions policy violation: camera is not allowed in this document"*
(Google รับทราบแล้วในบั๊ก 486623612 และ 486922850 ยังไม่มีทางแก้ และแนะนำเองให้ย้ายส่วนกล้องออกไปโฮสต์ที่อื่น)

หน้าเว็บจึงต้องอยู่บนโฮสต์ที่มี HTTPS เป็นของตัวเอง (ที่นี่ใช้ GitHub Pages) ส่วน Apps Script ยังทำหน้าที่เป็น backend เหมือนเดิม

**กล้องจะทำงานได้เฉพาะเมื่อเปิดผ่าน `https://...` หรือ `http://localhost` เท่านั้น** — ดับเบิลคลิกเปิดไฟล์ `index.html` ตรง ๆ ใช้กล้องไม่ได้

## ติดตั้ง

### 1. เตรียม Google Sheet และ Apps Script

1. สร้าง Google Sheet ใหม่ 1 ไฟล์
2. เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดตัวอย่างทิ้ง แล้ววางเนื้อหาทั้งหมดของ `Code.gs` ลงไป
4. เลือกฟังก์ชัน `setupSheets` แล้วกด **Run** หนึ่งครั้ง (จะขออนุญาตเข้าถึง Sheet/Drive — กดอนุญาต)
   ระบบจะสร้างแท็บทั้ง 5 พร้อมหัวคอลัมน์และค่าตั้งต้นให้เอง
5. กด **Deploy > New deployment** เลือกชนิด **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. คัดลอก URL ที่ลงท้ายด้วย `/exec` เก็บไว้

> ทุกครั้งที่แก้ `Code.gs` ต้องกด **Deploy > New deployment** ใหม่ — การกด Save เฉย ๆ ไม่อัปเดต URL `/exec`

### 2. เตรียมโฟลเดอร์เก็บรูปใน Google Drive

1. สร้างโฟลเดอร์ใน Drive เช่น `TimeTracking Photos`
2. เปิดโฟลเดอร์ แล้วดูรหัสจาก URL: `https://drive.google.com/drive/folders/`**`<รหัสตรงนี้>`**
3. เอารหัสไปใส่ในหน้า **ตั้งค่า** ของเว็บ (หรือใส่ตรง ๆ ในแท็บ `Settings` แถว `DriveFolderId`)

ถ้าเว้นว่างไว้ ระบบจะยังบันทึกเวลาได้ตามปกติ เพียงแต่ไม่เก็บรูป

### 3. ตั้งค่าหน้าเว็บ

เปิด `app.js` แก้บรรทัดบนสุด:

```js
const API_URL = 'https://script.google.com/macros/s/....../exec';  // URL จากขั้นตอนที่ 1
const API_TOKEN = '';                                              // ดูหัวข้อความปลอดภัยด้านล่าง
const DEVICE_NAME = 'จุดสแกนหลัก';                                  // ชื่อจุดสแกน (ถ้ามีหลายจุด)
```

### 4. ทดลองใช้บนเครื่องตัวเอง

```bash
python -m http.server 8000
# หรือ
npx serve .
```

แล้วเปิด `http://localhost:8000` (กล้องใช้งานได้เพราะ localhost นับเป็น secure context)

### 5. ขึ้น GitHub Pages

```bash
git init
git add .
git commit -m "ระบบบันทึกเวลาทำงานด้วยการสแกนใบหน้า"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
git push -u origin main
```

จากนั้นที่หน้า repo บน GitHub: **Settings > Pages > Source: Deploy from a branch > main / (root) > Save**
รอสักครู่จะได้ URL `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` เอาไปเปิดบนแท็บเล็ต/มือถือที่หน้างานได้เลย

## วิธีใช้งาน

1. **พนักงาน** — เพิ่มรายชื่อพนักงานให้ครบก่อน
2. **ลงทะเบียนใบหน้า** — เลือกพนักงาน แล้วเก็บภาพ 3 มุม (หันตรง / เอียงซ้าย / เอียงขวา) แล้วกดบันทึก
   ทำครั้งเดียวต่อคน ยกเว้นเปลี่ยนลุคไปมาก (ตัดผมสั้นมาก เริ่มใส่แว่น) ค่อยลงทะเบียนใหม่ทับ
3. **สแกนเข้า-ออกงาน** — กดปุ่ม **"เริ่มสแกน"** กล้องจึงจะเปิด (เปิดหน้าเว็บเฉย ๆ กล้องจะไม่ติดเอง)
   จากนั้นเปิดค้างไว้ที่จุดสแกน พนักงานเดินมายืนหน้ากล้อง ระบบบันทึกให้เอง
   - โหมด **อัตโนมัติ**: สแกนครั้งแรกของวัน = เข้างาน, ครั้งถัดไป = ออกงาน
   - เลือกโหมด **เข้างาน** / **ออกงาน** ล็อกไว้ก็ได้ ถ้าอยากคุมเอง
   - กด **"หยุดสแกน"** เพื่อปิดกล้องเมื่อพักหรือเลิกใช้ (เปลี่ยนไปหน้าอื่นกล้องก็ปิดเองเช่นกัน)
4. **ภาพรวมวันนี้** — ดูว่าใครมาแล้ว ใครสาย ใครยังไม่มา
5. **ประวัติเวลาทำงาน** — ค้นตามช่วงวันที่/แผนก แก้เวลาด้วยมือได้ และส่งออก CSV เข้า Excel ได้

## แท็บใน Google Sheet

ทุกแท็บอ่าน/เขียนด้วย **ชื่อหัวคอลัมน์** ไม่ใช่ตำแหน่งคอลัมน์ — สลับลำดับคอลัมน์ได้อิสระ
แต่ถ้า **เปลี่ยนชื่อหัวคอลัมน์** ต้องไปแก้ชื่อใน `Code.gs`/`app.js` ให้ตรงกันด้วย มิฉะนั้นช่องนั้นจะอ่าน/เขียนเป็นค่าว่างเงียบ ๆ

| แท็บ | เก็บอะไร |
|---|---|
| `Employees` | รายชื่อพนักงาน — `EmployeeID` เป็นคีย์เชื่อมทุกแท็บ, `Status` = `ทำงาน` / `ลาออก` |
| `FaceData` | ใบหน้าที่ลงทะเบียน — หนึ่งคนมีหลายแถว (ค่าเฉลี่ย + แต่ละมุม) ตอนเทียบใช้ระยะที่ใกล้ที่สุด |
| `Attendance` | **หนึ่งแถวต่อพนักงานต่อวัน** — ตารางหลักที่ใช้อ่าน/ทำเงินเดือน |
| `ScanLogs` | บันทึกทุกครั้งที่สแกน รวมครั้งที่ซ้ำ ไว้ตรวจย้อนหลัง |
| `Settings` | ค่าตั้งค่าแบบ Key/Value แก้ได้จากหน้าเว็บหรือแก้ในชีตตรง ๆ |

### ค่าใน `Settings`

| Key | ค่าตั้งต้น | ความหมาย |
|---|---|---|
| `WorkStartTime` | `08:00` | เวลาเข้างานมาตรฐาน ใช้คำนวณ "สาย" |
| `WorkEndTime` | `17:00` | เวลาเลิกงาน (แสดงผลเท่านั้น) |
| `LateGraceMinutes` | `10` | เข้างานช้าไม่เกินนี้ยังถือว่าตรงเวลา |
| `BreakMinutes` | `60` | หักออกจากชั่วโมงทำงาน |
| `MinScanIntervalMinutes` | `5` | สแกนซ้ำภายในช่วงนี้ไม่บันทึกใหม่ |
| `MatchThreshold` | `0.45` | ระยะใบหน้าที่ยอมรับ — ยิ่งน้อยยิ่งเข้ม |
| `MatchMargin` | `0.05` | อันดับ 1 ต้องดีกว่าอันดับ 2 อย่างน้อยเท่านี้ |
| `DriveFolderId` | (ว่าง) | โฟลเดอร์เก็บรูป — เว้นว่าง = ไม่เก็บรูป |
| `PhotoSharing` | `anyone` | `anyone` = แชร์ลิงก์เพื่อให้รูปแสดงบนหน้าเว็บ, `private` = ไม่แชร์ |

**เวลาเข้างานเป็นค่าเดียวทั้งบริษัท** ถ้าต้องการกะที่ต่างกันรายคน ต้องเพิ่มคอลัมน์เวลาเข้า/ออกในแท็บ `Employees`
แล้วแก้ `applyAttendanceComputedFields_` ใน `Code.gs` ให้ดึงค่าจากพนักงานคนนั้นก่อน แล้วค่อย fallback มาที่ `Settings`

## ปรับความแม่นยำของการจับคู่ใบหน้า

การจับคู่จะผ่านก็ต่อเมื่อครบ **สองเงื่อนไข**: ระยะที่ใกล้ที่สุดต่ำกว่า `MatchThreshold` **และ** ห่างจากคนอันดับสองอย่างน้อย `MatchMargin`
เงื่อนไขที่สองคือตัวกันสับสนระหว่างคนหน้าคล้ายกัน — ถ้าคะแนนสองคนสูสีเกินไป ระบบจะถือว่าตัดสินไม่ได้ ดีกว่าเดาแล้วบันทึกผิดคน
นอกจากนี้ยังต้องเจอคนเดิมติดกัน 3 เฟรมก่อนจึงบันทึก เพื่อไม่ให้จับผิดตอนคนเดินผ่าน

| อาการ | วิธีแก้ |
|---|---|
| จำไม่ได้บ่อย / ต้องยืนนาน | เพิ่ม `MatchThreshold` เป็น `0.50` หรือลงทะเบียนใบหน้าใหม่ในที่ที่แสงเหมือนจุดสแกนจริง |
| บันทึกผิดคน | ลด `MatchThreshold` เป็น `0.40` และเพิ่ม `MatchMargin` เป็น `0.08` |
| ขึ้นว่า "ใบหน้าใกล้เคียงกันหลายคน" | ลงทะเบียนใบหน้าของคู่ที่สับสนใหม่ทั้งสองคน ให้ภาพชัดและแสงดี |

## ความปลอดภัยและความเป็นส่วนตัว

- **ไม่มีระบบล็อกอิน** และ Apps Script ถูก deploy แบบ "Anyone" — ใครรู้ URL `/exec` ก็ยิงคำขอได้
  ถ้าต้องการกันไว้ ให้ตั้งค่า `API_TOKEN` ให้ตรงกันทั้งใน `Code.gs` และ `app.js`
  (เป็นการกันแบบพื้นฐาน — โทเคนอยู่ในไฟล์ JavaScript ที่ผู้ใช้เปิดดูได้ จึงกันคนทั่วไปได้ แต่ไม่ใช่ระบบยืนยันตัวตนจริง)
- **รูปถ่ายถูกแชร์แบบ "ใครมีลิงก์ก็ดูได้"** โดยค่าตั้งต้น เพราะหน้าเว็บที่ไม่ได้ล็อกอินต้องดึงรูปมาแสดงให้ได้
  ถ้าไม่ต้องการ ให้ตั้ง `PhotoSharing` = `private` (รูปจะยังถูกเก็บ แต่จะไม่แสดงบนหน้าเว็บ) หรือเว้น `DriveFolderId` ไว้เพื่อไม่เก็บรูปเลย
- **ข้อมูลใบหน้าที่เก็บเป็นเวกเตอร์ตัวเลข 128 ค่า ไม่ใช่รูปภาพ** และย้อนกลับเป็นรูปหน้าไม่ได้ แต่ยังถือเป็นข้อมูลชีวมาตร
  ควรแจ้งและขอความยินยอมจากพนักงานก่อนลงทะเบียน
- **ระบบนี้ไม่มีการตรวจว่าเป็นคนจริง (liveness detection)** — ถือรูปถ่ายหรือจอมือถือมาส่องกล้องก็ผ่านได้
  จึงออกแบบให้ **หัวหน้างานเป็นคนถือ/ดูแลกล้อง** เป็นตัวควบคุมแทน ไม่ควรปล่อยให้พนักงานสแกนกันเองโดยไม่มีคนดู

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ขึ้น "ยังไม่ได้ตั้งค่า API_URL" | ยังไม่ได้ใส่ URL `/exec` ใน `app.js` |
| กล้องไม่ติด ขึ้นว่าต้องใช้ https | เปิดหน้าเว็บผ่าน `file://` หรือ `http://` ที่ไม่ใช่ localhost — ต้องใช้ GitHub Pages หรือ localhost |
| กล้องขึ้น "ไม่ได้รับอนุญาต" | กดอนุญาตกล้องที่ไอคอนซ้ายแถบที่อยู่ของเบราว์เซอร์ แล้วรีเฟรช |
| โหลดโมเดลไม่สำเร็จ | โฟลเดอร์ `models/` ไม่ได้ถูกอัปโหลดขึ้น GitHub Pages — ตรวจว่า commit ไฟล์ `.bin` ไปด้วย |
| บันทึกไม่ได้ ขึ้น error เกี่ยวกับ CORS | มีการเติม header `Content-Type` ใน `apiPost()` — ต้องไม่ใส่ (ดูหมายเหตุใน `app.js`) |
| แก้ `Code.gs` แล้วไม่มีอะไรเปลี่ยน | ยังไม่ได้ **Deploy > New deployment** |
| เวลาที่บันทึกเพี้ยนไปหลายชั่วโมง | เขตเวลาของสคริปต์ไม่ตรง — ตั้งที่ Apps Script: **Project Settings > Time zone** เป็น `Asia/Bangkok` |

## หมายเหตุสำหรับผู้พัฒนา

ไม่มี build step และไม่ต้องติดตั้ง dependency ใด ๆ ตรวจไวยากรณ์และรันชุดทดสอบด้วย:

```bash
node --check app.js && node --check face.js
cp Code.gs /tmp/Code.gs.js && node --check /tmp/Code.gs.js

node tests/test-face.js    # ตรรกะการจับคู่ใบหน้า: threshold, margin, การยืนยัน 3 เฟรม
node tests/test-code.js    # ตรรกะเวลา: การนับสาย, ชั่วโมงทำงาน, การอ่านวันที่จากชีต
```

ชุดทดสอบครอบคลุมเฉพาะ**ตรรกะล้วน ๆ** ที่ไม่พึ่งกล้องหรือ Google (`tests/test-code.js` จำลอง `Utilities`/`Session`
เท่าที่ตรรกะนั้นเรียกใช้) ส่วนที่แตะชีต/ไดรฟ์จริงยังต้องทดสอบกับของจริง เพราะ `SpreadsheetApp`, `DriveApp`,
`LockService` มีอยู่เฉพาะใน runtime ของ Apps Script
